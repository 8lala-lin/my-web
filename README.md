# Designer Portfolio Website

A responsive single-page designer portfolio with Chinese/English switching, an overlapping project-card carousel, project detail dialogs, category filters, and mobile layout.

## Publish with GitHub Pages

1. Create a new repository on GitHub. For the simplest free setup, make it public.
2. Extract this ZIP file on your computer.
3. Upload the files inside this folder (`index.html`, `README.md`, and `.nojekyll`) to the **root** of your repository.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the publishing process to finish. GitHub Pages will show your public URL in **Settings → Pages**.

## Notes

- Do not upload the ZIP as the only repository file. Extract it first and upload the files inside.
- This is a static site. No build command, Node.js, or backend is required.
- Replace the sample designer name, project copy, and `hello@example.com` email before sharing it publicly.
- Access from mainland China may vary by network; test the published URL on the networks your audience uses.
